# Mysterious Vibes in Transylvania — Holiday Deal Page

A responsive holiday deal landing page for **Lowcost Vibes** showcasing a 4-day escape to Romania and Transylvania (`£249` per person, including return flights from London, 3 nights at Parliament Hotel Bucharest (4★), and a complimentary Transylvania Day Trip).

## Live Demo
- **Live URL:** https://transylvania-holiday-deal.netlify.app

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript / React
- **Hosting & CI/CD:** Netlify (connected to GitHub)
